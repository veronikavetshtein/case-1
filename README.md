# Наставник.Аналитика — система анализа отчётов наставников фонда «Волонтёры в помощь детям-сиротам»

Комплексное решение для автоматизированного анализа еженедельных отчётов волонтёров-наставников по 16 основным направлениям, 3 обобщающим вопросам анкеты (17–19), детекции 3 типов «красных флагов», кластеризации неучтённых тем, обратимой псевдонимизации лиц и выгрузки данных в CRM фонда на базе 1С.

---

### Быстрый старт

1. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```
2. Запустите пакетный анализ выгрузки `reports.xlsx` (по умолчанию в режиме `auto`: использует локальную Ollama при её наличии, OpenAI-совместимый API при заданном ключе или встроенный локальный лингвистический анализатор без GPU):
   ```bash
   python batch_process.py --fast
   ```
3. Запустите веб-интерфейс координатора:
   ```bash
   python -m streamlit run app.py
   ```
   *(Также запуск и пересчёт анализа доступны непосредственно из боковой панели веб-интерфейса Streamlit без использования консоли).*

4. Проверка качества модели на эталонном бенчмарке (Gold Benchmark):
   ```bash
   python quality_check.py benchmark --provider offline
   ```

---

### Архитектура и состав проекта

- `parser.py` — импорт 1С-выгрузки (`reports.xlsx`): сохраняет номер исходной строки Excel (`source_row`), код наставника (`volunteer_id`), кейс (`case_id`), дату и текст отчёта, корректно отделяет пустые строки и технические дубликаты.
- `criteria.py` и `criteria_store.py` — единый реестр 16 базовых критериев, 3 обобщающих вопросов анкеты (17–19) и 10 маркеров риска выгорания; поддержка добавления и редактирования критериев без изменения кода (`criteria_config.json`).
- `llm_client.py` — гибридный клиент анализа текста:
  - Поддерживает 4 режима (`provider` в `config.yaml`): `auto`, `ollama` (`qwen2.5:3b-instruct`), `openai` (OpenAI / OpenRouter / vLLM) и `offline` (встроенный русский лингвистический анализатор).
  - Оценивает каждый критерий по шкале `0` (нет сведений), `1` (упоминание / действие наставника), `2` (явно описанная положительная динамика / изменение у подопечного) с проверкой точного вхождения дословной цитаты в исходный отчёт.
  - Автоматически обезличивает имена перед отправкой во внешнюю/локальную LLM и восстанавливает исходные цитаты для координатора.
- `burnout_rules.py` — двухэтапный алгоритм детекции риска выгорания:
  - На первом шаге фиксируются маркеры 1–10 исключительно у **автора отчёта (наставника)** с фильтрацией высказываний, где субъектом усталости или отказа от встречи является ребёнок.
  - На втором шаге сигнал «красного флага» формируется **только при наличии маркеров в ≥2 последовательных отчётах одной пары** (`volunteer_id + case_id`) в хронологическом порядке.
- `pseudonymize.py` — автоматическая обратимая псевдонимизация упоминаемых лиц:
  - Распознаёт русские имена (полные и уменьшительные формы во всех 6 падежах: *Ваня/Вани/Ваней*, *Маша/Машей/Машу*), отчества и фамилии (*Кристина Панкова*, *Наталья Сергеевна*, *Екатерина Самсонова*).
  - Объединяет падежные формы одного человека в единый канонический идентификатор `[ЛИЦО_N]` и гарантирует 100% посимвольное обратное восстановление (`restore(masked, mapping) == original`).
- `topic_suggestions.py` — поиск неучтённых тем:
  - Семантическая и TF-IDF кластеризация фрагментов отчётов, не покрытых 16 базовыми критериями, с автоматическим предложением новых критериев и добавлением их в один клик из интерфейса.
- `quality_check.py` — пайплайн проверки качества при смене модели или провайдера:
  - Встроенный эталонный набор (`GOLD_BENCHMARK`, 10 сценариев с проверкой шкалы `0/1/2`, дословности цитат и ловушек субъекта высказывания) + генерация выборки `gold_template_PRIVATE.csv` и расчёт `Precision / Recall / F1`.
- `reviews.py` — хранение решений координатора (`Не проверено` / `Подтверждено` / `Отклонено` + комментарий) в локальной БД SQLite (`coordinator_reviews.sqlite3`) и формирование таблиц экспорта для CRM фонда на базе 1С (сводная ведомость по волонтёрам и реестр сигналов в форматах CSV и `.xlsx`).
- `app.py` — интерактивный дашборд Streamlit (11 вкладок: макро/микро-аналитика, вопросы 17–19, красные флаги, 16 критериев, кластеризация новых тем, история пар, проверка координатора, настройка критериев и правил, бенчмарк качества и псевдонимизация, экспорт для 1С CRM).
